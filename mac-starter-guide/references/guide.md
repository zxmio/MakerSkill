# MacBook 上手使用指南（陪跑学员版）

更新：2026-11-25。

不少同学是第一次用 Mac，或者刚从 Windows 换过来。

Mac 不难，但有一些地方和 Windows 不一样：关了窗口程序还开着，没有「剪切」，右键要两根手指点。这些小地方不知道，就会在带练时卡住。

这份指南只讲上课和日常干活真正用得到的。先花半小时照着过一遍，再去做《MacBook 配置清单》，会顺很多。

---

## 一、从 Windows 换过来，先看这张表

| 想做的事 | Windows 上 | Mac 上 |
|---|---|---|
| 复制、粘贴 | `Ctrl + C`、`Ctrl + V` | `Command + C`、`Command + V` |
| 右键菜单 | 点鼠标右键 | 两根手指一起点触控板 |
| 找文件 | 文件资源管理器 | 访达 |
| 找软件、搜东西 | 开始菜单 | 聚焦搜索（`Command + 空格`） |
| 改设置 | 控制面板、设置 | 系统设置 |
| 回收站 | 回收站 | 废纸篓 |
| 删除文件 | `Delete` | `Command + Delete` |
| 重命名 | `F2` | 选中文件，按回车 |
| 截图 | `Win + Shift + S` | `Shift + Command + 4` |
| 切换程序 | `Alt + Tab` | `Command + Tab` |
| 卡死了结束程序 | 任务管理器 | 强制退出（`Option + Command + Esc`） |
| 关掉程序 | 点窗口右上角的叉 | `Command + Q`（点左上角红点只是关窗口） |

记住一条就够了：**Windows 上用 `Ctrl` 的快捷键，Mac 上基本换成 `Command`。**

`Command` 键在空格键两边，上面印着 `⌘` 符号。

## 二、开机和系统设置

### 2.1 登录 Apple 账户

Apple 账户（以前叫 Apple ID）是你在苹果所有设备上的身份。登录以后，App Store 能下软件，iPhone 和 Mac 之间才能互传文件。

1. 点屏幕左上角的苹果图标。
2. 点「系统设置」。
3. 点左侧最上面的「登录」（或者显示你名字的那一栏）。
4. 输入你 iPhone 上登录的那个 Apple 账户和密码。
5. 按提示在 iPhone 上确认验证码。

检查一下：系统设置左上角显示出你的名字和头像，就登录好了。

**注意。** Mac 和 iPhone 要登录同一个 Apple 账户，后面第七节的互传才能用。

### 2.2 设置触控板

Mac 的触控板很好用，先把几个开关打开。

1. 打开「系统设置」，点左侧的「触控板」。
2. 在「光标与点按」里，打开「轻点来点按」。以后轻轻碰一下就是点击，不用按下去。
3. 确认「辅助点按」是「双指点按或轻点」。这就是右键。

常用手势：

| 手势 | 作用 |
|---|---|
| 一根手指轻点 | 点击 |
| 两根手指轻点 | 右键菜单 |
| 两根手指上下滑 | 滚动页面 |
| 两根手指捏合、张开 | 缩小、放大 |
| 三根手指往上推 | 看到所有打开的窗口（调度中心） |
| 三根或四根手指左右滑 | 切换桌面 |

**如果觉得滚动方向是反的。** Mac 默认是「手指往上推，页面往上走」，和 Windows 鼠标滚轮相反。不习惯的话：系统设置 → 触控板 → 「滚动缩放」，关掉「自然滚动」。

### 2.3 键盘和输入法

**切换中英文。** 先试前两种，哪个管用就用哪个：

- 按一下大写锁定键（`Caps Lock`，键盘左边写着 `中/英` 或 `⇪`）。
- 按 `Control + 空格`。
- 按地球仪键（键盘左下角的 `fn` 键）。有的电脑默认是这个功能，有的不是。

检查一下：屏幕右上角菜单栏的输入法图标，在「拼」和「A」之间来回变。

**加一个中文输入法。** 如果切不出中文：

1. 打开「系统设置」，点「键盘」。
2. 在「文字输入」那一栏，点「输入法」旁边的「编辑」。
3. 点左下角的「+」。
4. 选「简体中文」，再选「拼音 - 简体」，点「添加」。

**用自己习惯的输入法。** 想用微信输入法、搜狗输入法，去它们官网下载 Mac 版装好，再在上面第 3 步里把它加进来。

**注意。** 在终端里输命令时，先切到英文。中文状态下打出来的引号、空格是全角的，命令会报错。

## 三、访达和文件管理

访达就是 Mac 的文件管理器，相当于 Windows 的「此电脑」。程序坞最左边那个蓝白笑脸就是它。

### 3.1 常用位置

打开访达，左侧栏里这几个最常用：

| 位置 | 放什么 |
|---|---|
| 下载 | 浏览器下载的所有文件，默认都在这里 |
| 文稿 | 放你自己的文档，建议知识库也建在这里 |
| 桌面 | 屏幕上看到的那些文件，截图默认也存在这里 |
| 应用程序 | 装好的软件都在这里 |
| 隔空投送 | 和 iPhone、其他 Mac 互传文件 |

**下载的文件找不到。** 先去「下载」里找。还找不到，打开浏览器的下载列表，点文件旁边的放大镜图标，会直接打开它所在的文件夹。

### 3.2 新建、重命名、移动、删除

- **新建文件夹**：在访达窗口空白处，两根手指点一下，选「新建文件夹」。
- **重命名**：点选文件，按回车，输入新名字，再按回车。
- **复制文件**：选中文件，按 `Command + C`，到目标文件夹按 `Command + V`。
- **移动文件**（相当于剪切）：选中文件，按 `Command + C`，到目标文件夹按 `Option + Command + V`。也可以直接把文件拖过去。
- **删除**：选中文件，按 `Command + Delete`，文件进废纸篓。
- **彻底删除**：程序坞最右边的废纸篓上两根手指点一下，选「清倒废纸篓」。

**注意。** Mac 上没有「剪切文件」这个菜单。移动文件就用上面那个 `Option + Command + V`，或者直接拖。

### 3.3 看文件在哪：显示路径

AI 员工经常要你告诉它「文件在哪」。下面两招很常用：

- **显示路径栏**：在访达顶部菜单点「显示」，点「显示路径栏」。窗口底部会一直显示当前位置。
- **复制文件的完整路径**：选中文件，按 `Option + Command + C`。路径就复制好了，可以直接粘贴给 AI。

### 3.4 预览文件

选中一个文件，按一下空格键。不用打开软件，就能直接看到 PDF、图片、视频、Word 的内容。再按一下空格关掉。

### 3.5 压缩和解压

- **压缩**：选中文件或文件夹，两根手指点一下，选「压缩」。旁边会多出一个 `.zip` 文件。
- **解压 `.zip`**：双击它，就会在旁边解压出来。
- **解压 `.rar`、`.7z`**：Mac 自带的打不开。打开 App Store，搜「The Unarchiver」，装好以后双击就能解压。

### 3.6 看到隐藏的文件

有些配置文件名字以点开头（比如 `.claude`），平时是隐藏的。在访达里按 `Shift + Command + .`（句号），隐藏文件就显示出来了，再按一次又藏起来。

## 四、常用快捷键

### 4.1 文字和文件

| 快捷键 | 作用 |
|---|---|
| `Command + C` | 复制 |
| `Command + V` | 粘贴 |
| `Command + X` | 剪切（只对文字有用） |
| `Command + Z` | 撤销 |
| `Shift + Command + Z` | 重做 |
| `Command + A` | 全选 |
| `Command + F` | 在当前页面或文件里查找 |
| `Command + S` | 保存 |

### 4.2 截图和录屏

| 快捷键 | 作用 |
|---|---|
| `Shift + Command + 3` | 截整个屏幕 |
| `Shift + Command + 4` | 拖一个框，截框里的部分 |
| `Shift + Command + 4`，再按空格 | 鼠标变成相机，点哪个窗口就截哪个窗口 |
| `Shift + Command + 5` | 打开截图工具栏，可以录屏 |

截图默认存在桌面上。

**想截完直接粘贴给 AI 或微信。** 在上面的快捷键里再多按一个 `Control`，比如 `Control + Shift + Command + 4`。截图不存文件，直接进剪贴板，到对话框里按 `Command + V` 就贴上了。

**录屏。** 按 `Shift + Command + 5`，在底部工具栏选「录制整个屏幕」或「录制所选部分」，点「录制」。录完点菜单栏右上角的停止按钮，录屏文件也存在桌面。

**注意。** 第一次截图或录屏，有些软件会提示要「屏幕录制」权限。打开「系统设置」→「隐私与安全性」→「屏幕与系统音频录制」，把对应软件的开关打开。

### 4.3 窗口和程序

| 快捷键 | 作用 |
|---|---|
| `Command + 空格` | 聚焦搜索：找软件、找文件、算算数 |
| `Command + Tab` | 在打开的程序之间切换。按住 `Command`，多按几下 `Tab` 选 |
| ``Command + ` ``（数字 1 左边那个键） | 同一个程序的多个窗口之间切换 |
| `Command + W` | 关掉当前窗口或标签页 |
| `Command + Q` | 彻底退出程序 |
| `Command + M` | 把窗口收到程序坞 |
| `Command + H` | 隐藏当前程序 |
| `Command + ,`（逗号） | 打开当前程序的设置 |
| `Option + Command + Esc` | 强制退出卡死的程序 |

**关窗口和退出程序不一样。** 点窗口左上角的红点，只是关掉这个窗口，程序还在后台开着。程序坞里图标下面有一个小点，就说明它还开着。要彻底关掉，按 `Command + Q`。

## 五、软件怎么装和卸载

### 5.1 从 App Store 装

1. 打开 App Store（程序坞里蓝色的 A 字图标，或者用聚焦搜索找）。
2. 在左上角搜索框输入软件名。
3. 点「获取」，再点「安装」。
4. 按提示输入 Apple 账户密码，或者用指纹确认。

装好的软件会出现在「应用程序」里。

### 5.2 从官网下载装

《MacBook 配置清单》里大部分软件都是这样装的。下载下来一般是三种文件：

- **`.dmg` 文件**：双击打开，会弹出一个窗口。把里面的软件图标拖进「应用程序」文件夹。
- **`.pkg` 文件**：双击打开，一路点「继续」「同意」「安装」，中间输一次开机密码。
- **`.zip` 文件**：双击解压，把解压出来的软件拖进「应用程序」。

**装完记得推出安装盘。** 装 `.dmg` 后，访达左侧栏会多出一个带向上箭头的条目。点那个箭头，把它推出。

**注意。** 不要直接在 `.dmg` 弹出的窗口里双击运行软件。要先拖进「应用程序」，再从「应用程序」里打开。不然每次重启都要重新装。

### 5.3 把常用软件放进程序坞

1. 打开这个软件。
2. 在程序坞里它的图标上两根手指点一下。
3. 点「选项」，点「在程序坞中保留」。

### 5.4 卸载

1. 先按 `Command + Q` 退出这个软件。
2. 打开访达，点「应用程序」。
3. 找到这个软件，按 `Command + Delete`，它就进了废纸篓。
4. 清倒废纸篓。

有些大软件自带卸载程序。在「应用程序」里能看到「卸载 XXX」这样的程序，就用它来卸。

## 六、怎么打开终端

终端是一个用打字给电脑下命令的窗口。《MacBook 配置清单》从 Node.js 开始，好几步都要在终端里做。先学会打开它。

**方法一：聚焦搜索。**

1. 按 `Command + 空格`。
2. 输入「终端」两个字。
3. 按回车。

**方法二：从访达找。**

1. 打开访达，点「应用程序」。
2. 打开「实用工具」文件夹。
3. 双击「终端」。

检查一下：屏幕上出现一个窗口，最后一行有你的用户名，后面跟着一个 `%` 和一闪一闪的光标。

**先记住这几件事：**

- 命令从教程里复制过来，粘贴进终端，按回车才会执行。
- 等光标重新出现，才算这条命令跑完了。
- 输开机密码时屏幕上什么都不显示，是正常的，输完按回车就行。
- 想关掉终端，按 `Command + Q`。装完新软件后，要退出终端再重新打开，它才认得新软件。

做完这一节，就可以去做配置清单了。

## 七、iPhone 和 Mac 互传

### 7.1 先做好准备

下面两个功能都要满足这几条：

- Mac 和 iPhone 登录的是同一个 Apple 账户。
- 两台设备都打开了 Wi-Fi 和蓝牙。
- 两台设备离得不远，十米以内。

### 7.2 隔空投送：传文件、照片

**从 iPhone 传到 Mac：**

1. 在 iPhone 上选好照片或文件，点「分享」按钮（一个方框加向上的箭头）。
2. 点「隔空投送」。
3. 在列表里点你的 Mac。

文件会直接存进 Mac 的「下载」文件夹。

**从 Mac 传到 iPhone：**

1. 在访达里选中文件，两根手指点一下。
2. 点「共享」，再点「隔空投送」。
3. 在弹出的窗口里点你的 iPhone。

**找不到对方设备。**

1. 在 Mac 上打开访达，点左侧的「隔空投送」。
2. 在窗口底部，把「允许这些人发现我」改成「所有人」。
3. 在 iPhone 上，打开「设置」→「通用」→「隔空投送」，选「所有人（10 分钟）」。

### 7.3 通用剪贴板：在 iPhone 上复制，在 Mac 上粘贴

先把「接力」打开：

1. Mac：打开「系统设置」→「通用」→「隔空投送与接力」，打开「允许在这台 Mac 和 iCloud 设备之间使用接力」。
2. iPhone：打开「设置」→「通用」→「隔空播放与接力」，打开「接力」。

然后就能用了：

1. 在 iPhone 上复制一段文字或一张图。
2. 在 Mac 上按 `Command + V`。

刚复制的内容就贴过来了，反过来也一样。在手机上看到一段好文案，想贴给电脑上的 AI，用这个最快。

## 八、常见问题

### 8.1 打开软件提示「无法打开，因为无法验证开发者」

这是 Mac 的安全拦截。从官网下载的软件有时会被拦住。

1. 点「好」，关掉提示。
2. 打开「系统设置」，点「隐私与安全性」。
3. 往下滚到「安全性」那一栏，找到这个软件被阻止的提示。
4. 点「仍要打开」。
5. 输一次开机密码。

**注意。** 只对你从官网下载的软件这么做。来路不明的软件被拦住，就别打开了。

### 8.2 磁盘满了

先看是什么占了空间：

1. 打开「系统设置」，点「通用」，点「储存空间」。
2. 等它算完，会按类别显示占用。

再按下面的顺序清理：

1. 清倒废纸篓。
2. 打开访达的「下载」文件夹，把装好软件剩下的 `.dmg`、`.pkg` 安装包删掉。
3. 在「储存空间」页面里，点各个类别后面的「i」按钮，按大小排序，删掉不要的大文件。
4. 卸载不用的软件，方法见 5.4。

**注意。** 硬盘剩余空间少于 20GB，系统和软件都会变慢，装软件也可能失败。

### 8.3 软件卡住了，点什么都没反应

1. 按 `Option + Command + Esc`。
2. 在弹出的列表里选中卡住的软件。
3. 点「强制退出」。

也可以在程序坞里，按住 `Option` 键，用两根手指点这个软件的图标，选「强制退出」。

**整台电脑都卡住了。** 长按电源键（触控 ID 那个键）十秒左右，屏幕黑掉后再按一下开机。这是最后的办法，没保存的内容会丢。

### 8.4 不知道一个快捷键或设置在哪

直接问你的 AI 员工。比如：「Mac 上怎么把截图默认存到下载文件夹？」它会一步步告诉你。

## 九、卡住了怎么办

1. 把那一屏截图（`Shift + Command + 4`），发到群里，说清楚你在做哪一步。
2. 先跳过，接着做后面的。
3. 留到带练时，我们一起看。

上手 Mac 一般一两天就习惯了。过完这份指南，接着打开《MacBook 配置清单》，把干活要用的软件装好。
