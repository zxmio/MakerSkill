# MacBook 电脑配置清单（陪跑学员版）

更新：2026-11-25，所有下载地址当天核对过。

我们第一次带练前，请你先把电脑配好。

带练的时间很宝贵。我希望那一个多小时，用来跟 AI 一起把你的事做出来，而不是一起盯着进度条装软件。

第一次用 Mac，或者刚从 Windows 换过来的同学，先看《MacBook 上手使用指南》，再回来做这份清单。

这份清单按顺序排好了，从上往下做，做完一项打一个勾。全部做完大概要 1.5 到 2 个小时，网络顺的话更快。

有两种情况可以先放一放：

- 第 8 到 11 项（给 Claude 接上模型）要注册、充值，拿不准的可以留到第一次带练，我们一起做。
- 选装的两项，用到再装。

卡在哪一步都别硬扛，把那一屏截图发到群里。

## 二、开工前三条规矩

1. 命令一律从这份清单的灰色代码框里复制，不要手打。大小写、空格、横线错一个都不行。
2. 命令粘贴进终端后，按回车才会执行。
3. 等终端重新出现能输入的光标，才算这条命令跑完。中间滚出一大堆文字是正常的。

**注意。** 终端里输开机密码时，屏幕上什么都不显示，没有星号也没有圆点。这是正常的，照常输完按回车就行。

**账号一律注册在你自己名下。** 用你自己的邮箱和手机号，钱也充在自己的账号里。用别人的账号，做到一半要迁移，会很麻烦。

## 0. 开工前检查

### 0.1 看一眼你的电脑

1. 点屏幕左上角的苹果图标。
2. 点「关于本机」。
3. 看「芯片」那一行：写着 Apple M 开头的，是苹果芯片；写着 Intel 的，是英特尔芯片。记下来，后面下载时可能要选。
4. 看「macOS」那一行的版本号。建议升级到最新版。Claude Code 要求 macOS 13 或更新。

升级系统：点苹果图标，点「系统设置」，点「通用」，点「软件更新」。

### 0.2 准备好开机密码

后面装软件时，会要你输好几次开机密码。

**注意。** 如果你用的是公司配的电脑，先确认自己有管理员权限。能自己装上下面的 Chrome，就说明有权限。

### 0.3 留够硬盘空间

1. 点苹果图标，点「系统设置」，点「通用」，点「储存空间」。
2. 看剩余空间。建议至少留 20GB。

### 0.4 检查网络

ChatGPT、Claude、GitHub 这些服务都在海外。你需要一个能稳定打开海外网站的网络。

「稳定」比「能打开」更重要。时好时坏的网络，会让安装卡在一半，报一些看起来跟网络毫无关系的错。

这份清单不推荐具体的网络工具。如果你现在没有这样的网络，先在群里说一声，我们一对一确认方案。

用浏览器依次打开下面几个网址，每个都应该在几秒内正常显示：

```text
https://chatgpt.com
https://claude.ai
https://github.com
https://nodejs.org
```

检查一下：四个网址都能正常打开，图片和文字都显示完整，就通过了。有一个一直转圈，就是网络还没准备好。

终端那一关的网络检查，放在第 5 项学会打开终端之后再做。

- [ ] 记下了芯片类型，系统已更新
- [ ] 知道开机密码，电脑有管理员权限
- [ ] 硬盘剩余 20GB 以上
- [ ] 浏览器能稳定打开上面四个网址

## 1. Chrome 浏览器

**干什么用。** 打开各种网站、平台后台，看 AI 帮你做出来的网页效果。Safari 也能用，但有些后台和插件在 Chrome 上更顺。

**下载地址。**

```text
https://www.google.com/chrome/
```

打不开的话，用这个中文页：

```text
https://www.google.cn/chrome/
```

**怎么装。**

1. 点页面上的「下载 Chrome」。
2. 打开「访达」里的「下载」文件夹，双击 `googlechrome.dmg`。
3. 把 Chrome 图标拖进「应用程序」文件夹。
4. 打开「应用程序」，双击 Google Chrome。
5. 如果弹出「这是从互联网下载的 App，确定要打开吗」，点「打开」。

**怎么验证。** Chrome 能打开，能正常访问 `https://chatgpt.com`。

- [ ] Chrome 已安装，能打开

## 2. 腾讯会议

**干什么用。** 我们一对一带练用腾讯会议。你共享屏幕，我看着你的电脑一步步带你做。

**下载地址。**

```text
https://meeting.tencent.com/download/
```

**怎么装。**

1. 在下载页找到 Mac 版，点下载。
2. 打开下载好的 `.dmg` 文件，把腾讯会议拖进「应用程序」。
3. 打开腾讯会议，用微信或手机号登录。

**怎么验证。** 提前测一次共享屏幕：

1. 点「快速会议」，开一个只有你自己的会议。
2. 点「共享屏幕」。
3. 选「整个屏幕」或「桌面」，不要选某一个窗口。
4. 用手机加入同一个会议，看手机上能不能看到你整个电脑屏幕。

检查一下：手机上能看到你电脑的整个桌面，切到别的软件，手机上也跟着变，就对了。

**常见问题。**

- 第一次共享屏幕会提示要「屏幕录制」权限。点苹果图标，点「系统设置」，点「隐私与安全性」，点「屏幕与系统音频录制」，打开腾讯会议的开关，然后重启腾讯会议。
- 手机上只看到一个窗口：说明你选的是共享某个窗口，重新共享，选「整个屏幕」。

- [ ] 腾讯会议已安装，能共享整个屏幕

## 3. ChatGPT 桌面版（含 Codex）

**干什么用。** 这是你的主力 AI 员工。ChatGPT 和 Codex 现在是同一个桌面软件里的两种模式：ChatGPT 偏聊天，Codex 是工作模式，能读写你电脑上的文件、帮你干活、调用技能。陪跑里大部分事情都在 Codex 里做。

**下载地址。**

```text
https://chatgpt.com/download/
```

**你需要准备。** 一个你自己的 ChatGPT 账号。账号和套餐怎么选，开始前在群里问我。

**怎么装。**

1. 打开下载页，点 macOS 版的下载按钮。
2. 打开「访达」里的「下载」文件夹，双击下载好的 `.dmg` 文件。
3. 把图标拖进「应用程序」文件夹。
4. 打开「应用程序」，双击打开它。
5. 如果弹出「这是从互联网下载的 App，确定要打开吗」，点「打开」。
6. 用你自己的 ChatGPT 账号登录。

**怎么验证。**

1. 在软件里切到 Codex。
2. 点「新对话」。
3. 输入下面这句，按回车：

```text
用一句话介绍你自己
```

检查一下：它回了你一段自我介绍，就装好了。

**常见问题。**

- 让它装技能、读文件时，会弹出权限请求。陪跑里我们一般选「允许完全访问」，它才能顺利干活。
- 登录页一直转圈：先回第 0.4 项检查网络。

- [ ] ChatGPT 桌面版已安装，Codex 能对话

## 4. Obsidian

**干什么用。** 你的知识库。资料、笔记、AI 写出来的东西都放在这里。它存的是你电脑上的普通文件，所以 Codex 和 Claude 都能直接读写。

**下载地址。**

```text
https://obsidian.md/download
```

**怎么装。**

1. 在下载页点 macOS 版下载。
2. 打开下载好的 `.dmg` 文件，把 Obsidian 拖进「应用程序」。
3. 打开 Obsidian。

**建你的第一个库。** 库就是一个文件夹，你的所有笔记都放在里面。

1. 打开 Obsidian，点「创建新仓库」（英文界面是「Create new vault」）。
2. 仓库名称填你的名字，比如「张三的知识库」。
3. 位置选「文稿」文件夹。
4. 点「创建」。

**怎么验证。**

1. 在左侧点「新建笔记」。
2. 随便写一句话。
3. 打开「访达」，进「文稿」里你的知识库文件夹，能看到这篇笔记，就对了。

**顺手做一件事。** 界面是英文的话：点左下角齿轮图标，进「General」，把「Language」改成「简体中文」，按提示重启。

- [ ] Obsidian 已安装，建好了自己的知识库

## 5. 学会打开终端

**干什么用。** 终端是 Mac 自带的一个窗口，用打字的方式给电脑下命令。后面装 Node.js、Git、Claude Code 都要用它。不用装，学会打开就行。

**怎么打开。**

1. 按键盘上的 `Command + 空格`，屏幕中间弹出一个搜索框。
2. 输入「终端」两个字。
3. 按回车。

检查一下：屏幕上出现一个窗口，最后一行有你的用户名，后面跟着一个 `%` 符号和一闪一闪的光标。

**顺手做一件事。** 在屏幕底部的程序坞里右键终端图标，点「选项」，点「在程序坞中保留」。

**终端网络检查。** 浏览器能打开海外网站，不等于终端也能连上。在终端里粘贴下面这行，按回车：

```bash
curl -I https://github.com
```

检查一下：返回一串文字，第一行写着 `HTTP/2 200`，说明终端能连上。

如果等了很久没反应，或者出现 `Could not resolve host`、`Failed to connect`、`timed out`，就是终端走不通。把这一屏截图发到群里。

- [ ] 能打开终端
- [ ] 终端网络检查返回 200

## 6. Node.js

**干什么用。** AI 员工干活时要用的工具箱。很多技能（比如做视频、处理图片）要靠它才能跑起来。它自带一个叫 npm 的下载工具。

**先检查有没有装过。** 在终端里输入下面这行，按回车：

```bash
node -v
```

- 显示 `v` 开头的数字，开头是 20 或更大，比如 `v24.` 或 `v26.`：已经装好了，跳到下面「换国内镜像」。
- 显示 `command not found: node`，或者开头的数字是 18 或更小：接着往下装。

**下载地址。**

```text
https://nodejs.org/en/download
```

**怎么装。**

1. 在下载页选标着 LTS 的版本。LTS 是长期支持版，最稳。写这份清单时是 v26。
2. 如果页面让你选系统和安装方式：系统选 macOS，方式选安装包（Installer，`.pkg` 结尾的文件）。
3. 打开下载好的 `.pkg` 文件。
4. 一路点「继续」「同意」「安装」，中间输一次开机密码。
5. 看到「安装成功」，点「关闭」。
6. 按 `Command + Q` 完全退出终端，再重新打开。

**注意。** 第 6 步很多人会漏。终端只在打开的那一刻认一次装了什么，不重开，它就还是不认识 node。

**怎么验证。** 在新打开的终端里输入：

```bash
node -v
```

再输入：

```bash
npm -v
```

检查一下：两条命令各显示一串数字，就装好了。

**换国内镜像。** npm 默认从海外下载，国内常常很慢。换成国内镜像会快很多。粘贴下面这行，按回车：

```bash
npm config set registry https://registry.npmmirror.com
```

这条命令执行后什么都不显示，是正常的。再粘贴这行确认：

```bash
npm config get registry
```

检查一下：显示 `https://registry.npmmirror.com/`，就换好了。

- [ ] `node -v` 显示 v20 以上的版本号
- [ ] npm 已换成国内镜像

## 7. Git

**干什么用。** 给文件存档、回退的工具，像游戏存档一样，改坏了能退回去。AI 改你的文件和做项目时会用到它。Mac 的 Git 跟着苹果的「命令行开发者工具」一起来。

**先检查。** 在终端里输入：

```bash
git --version
```

- 显示 `git version` 加一串数字：已经有了，这一项做完了。
- 弹出一个窗口，问你要不要安装「命令行开发者工具」：接着往下做。

**怎么装。**

1. 在弹出的窗口里点「安装」。
2. 点「同意」。
3. 等它装完，可能要十几分钟。

如果没有弹窗，在终端里粘贴下面这行，按回车，就会弹出来：

```bash
xcode-select --install
```

**怎么验证。** 装完再输一次：

```bash
git --version
```

检查一下：显示 `git version` 加一串数字，就装好了。

**常见问题。** 网络慢、一直装不完：先跳过，接着做后面的，带练时我们再一起处理。

- [ ] `git --version` 显示版本号

## 8. Claude Code

**干什么用。** 第二位 AI 员工，Claude 写作、做视频很强。它装在终端里，后面第 11 项会把它接进 Obsidian，你就不用面对终端了。

我们给 Claude 接模型用的是 API 方式，按用量付费，不注册 Claude 官方账号。所以装完先不要登录，接上模型的事在第 9、10 项做。

**怎么装。** 在终端里粘贴下面这行，按回车：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

这条命令下载时没有进度显示，等光标重新出现就行。

**怎么验证。**

1. 按 `Command + Q` 退出终端，再重新打开。
2. 输入：

```bash
claude --version
```

检查一下：显示一串版本号，后面可能跟着 `(Claude Code)`，就装好了。

**常见问题。**

- 提示 `command not found: claude`：先确认重开过终端。还不行，把安装时那一屏的文字截图发到群里。
- 安装命令一直卡住，或者报错：多半是网络。也可以换用下面这种装法，它走第 6 项换好的国内镜像：

```bash
npm install -g @anthropic-ai/claude-code
```

如果这条报 `EACCES` 或 `permission denied`，截图发到群里，我们一起处理。两种装法选一种，不要都装。

- [ ] `claude --version` 显示版本号

## 9. 模型超市账号和 API Key

**干什么用。** 模型超市是卖模型调用的平台。充值以后，你会拿到一串叫 API Key 的口令。它像一张会花钱的加油卡：Claude Code 每干一次活，就从你的余额里扣一点，不用不扣。

**用哪家。** 以我在群里发给你的平台和地址为准。下面按通用流程写，各家都是注册、充值、创建 Key 三步。

**怎么做。**

1. 打开我发给你的模型超市网址。
2. 点「注册」，用你自己的邮箱注册。
3. 登录后找「充值」或「钱包」，先充一个小金额，比如 50 元。
4. 找「API Keys」「令牌」或「密钥」，点「创建」。
5. 名字随便填一个认得出的，比如 `my-claude`。
6. 页面上会出现一长串 `sk-` 开头的字符，点旁边的复制按钮。
7. 把它粘贴到只有你自己能看到的地方存好，比如备忘录。
8. 在平台的文档里找到「Claude Code 接入」的说明，记下里面写的「接口地址」（也叫 Base URL）。

**注意。** 很多平台的 Key 只完整显示这一次。没存下来也不要紧，删掉重新建一个就行。

**API Key 怎么保管。**

- 不发到任何群里，不截图给别人看，包括我。
- 不写进任何文档和笔记。
- 怀疑泄露了，马上回模型超市把这个 Key 删掉，重新建一个。

- [ ] 模型超市已注册、已充值
- [ ] API Key 和接口地址已存好

## 10. CC Switch

**干什么用。** 一个开源小工具，把模型超市的地址和 Key 填进 Claude Code。你不用自己找配置文件，以后换一家模型超市，点一下就切过去。

**下载地址。**

```text
https://github.com/farion1231/cc-switch/releases
```

**注意。** 只从这个官方页面下载。CC Switch 会接触你的 API Key，网盘和群文件里的版本可能被人改过。

**怎么装。**

1. 打开下载页，找最上面标着 Latest 的版本。
2. 在它下面的「Assets」列表里，点 `macOS.dmg` 结尾的文件下载。写这份清单时文件名是 `CC-Switch-v4.0.40-macOS.dmg`，版本号以页面为准。
3. 双击下载好的 `.dmg`，把 CC Switch 拖进「应用程序」。
4. 打开 CC Switch。

**如果打开时提示「无法验证开发者」。**

1. 点「好」关掉提示。
2. 点苹果图标，点「系统设置」，点「隐私与安全性」。
3. 往下滚，找到 CC Switch 被阻止的提示，点「仍要打开」。
4. 输一次开机密码。

**添加模型超市。**

1. 在 CC Switch 窗口顶部选「Claude」标签。同一排还有 Codex 等标签，不要选错。
2. 点右上角的「+」号。
3. 预设列表里有你用的模型超市，就直接点它；没有，就选「自定义」。
4. 供应商名称：随便填，比如模型超市的名字。
5. API Key：粘贴第 9 项存好的那串 `sk-` 字符。
6. 请求地址（也可能叫 Base URL）：粘贴第 9 项记下的接口地址。
7. 点「添加」或「保存」。
8. 在新出现的卡片上点「启用」。

检查一下：卡片变成「使用中」或者高亮，就启用成功了。

**注意。** 粘贴 Key 和地址时，前后不要带空格，也不要带引号。多带一个空格就会报 401 错误，还很难看出来。

**怎么验证。**

1. 关掉所有终端窗口，重新打开一个。
2. 输入下面这行，按回车：

```bash
claude
```

3. 第一次启动会让你选界面颜色，用方向键选一个，按回车。
4. 如果问你是否信任这个文件夹，选「Yes」，按回车。
5. 在输入框里输入下面这句，按回车：

```text
用一句话介绍你自己
```

检查一下：它回了你一段自我介绍，说明 Claude Code 已经接上模型。输入 `/exit`，按回车退出。

**常见问题。**

- 启动后让你选登录方式，而不是出现输入框：回 CC Switch 确认卡片是「使用中」，再关掉终端重开。
- 报 `401` 或 `invalid api key`：Key 复制不全或带了空格。回 CC Switch 重新粘贴；还不行，就去模型超市新建一个 Key。
- 报余额不足：回模型超市充值。

- [ ] CC Switch 已安装，模型超市已启用
- [ ] 终端里 `claude` 能对话

## 11. MakerPilot 插件（在 Obsidian 里跟 AI 对话）

**干什么用。** MakerPilot 是 MakerOS 做的 Obsidian 插件。它把 AI 装进 Obsidian 的侧边栏，你在 Obsidian 里打字就能跟 Claude 对话，它能直接读写你知识库里的笔记，不用再开终端。同一个面板里还能切到 Codex，用的是第 3 项登录的 ChatGPT 账号。

它直接用第 8 到 10 项配好的 Claude Code，不用再填一遍 Key。所以前面三项要先做完。

**插件地址。**

```text
https://github.com/zxmio/MakerPilot
```

**你需要准备。** Obsidian 1.13.0 或更新的版本。点 Obsidian 左下角齿轮图标，进「设置」，点「关于」，能看到版本号；旧了就点「检查更新」。

MakerPilot 还没上架 Obsidian 的插件市场，我们用一个叫 BRAT 的小插件来装它。BRAT 专门安装 GitHub 上的插件，以后 MakerPilot 出新版，它会自动帮你更新。

**第一步：装 BRAT。**

1. 打开 Obsidian，点左下角齿轮图标，进「设置」。
2. 点「第三方插件」。
3. 如果看到「安全模式」是开着的，点「关闭安全模式」。
4. 点「浏览」。
5. 在搜索框里输入 `BRAT`。
6. 点 BRAT（作者 TfTHacker），点「安装」。
7. 装好后点「启用」。

**第二步：用 BRAT 装 MakerPilot。**

1. 按 `Command + P`，打开命令面板。
2. 输入 `BRAT`，选带「Add a beta plugin」字样的那一项。
3. 在弹出的输入框里粘贴上面的插件地址 `https://github.com/zxmio/MakerPilot`。
4. 版本选最新的，点「Add Plugin」。
5. 等右上角提示安装完成。
6. 回到「设置」→「第三方插件」，在已安装列表里找到 MakerPilot，打开开关启用。

**BRAT 装不上时，手动装。**

1. 打开下载页：

```text
https://github.com/zxmio/MakerPilot/releases/latest
```

2. 在「Assets」里下载 `main.js`、`manifest.json`、`styles.css` 三个文件。
3. 打开访达，进你的知识库文件夹，按 `Shift + Command + .` 显示隐藏文件夹。
4. 依次打开 `.obsidian`、`plugins`，在里面新建一个文件夹，名字叫 `makerpilot`。
5. 把下载的三个文件放进 `makerpilot` 文件夹。
6. 完全退出 Obsidian 再打开，到「设置」→「第三方插件」里启用 MakerPilot。

**怎么验证。**

1. 在 Obsidian 左侧竖排图标里，点新出现的 MakerPilot 图标，右侧会打开对话面板。
2. 点输入框下面的模型按钮，选 Claude 的 Opus。
3. 输入下面这句，按回车：

```text
你能看到我的知识库吗？里面现在有哪些笔记？
```

检查一下：它回答了，而且说出了你在第 4 项写的那篇笔记，就全部连通了。

**常见问题。**

- 面板里报错或者没反应：先回第 10 项，确认终端里 `claude` 能对话。终端那边通了，MakerPilot 才会通。
- 模型菜单里没有 Claude 或 Codex：进「设置」，点左侧的 MakerPilot，在「提供商」里启用 Claude Code 和 Codex。再打开 Codex 的模型设置，点「刷新」，勾选要用的模型。显示「可见 0」就是还没勾。
- 以前装过 Claudian：先在「第三方插件」里把 Claudian 关掉，两个一起开会冲突。
- 只支持电脑版 Obsidian，手机上用不了。

- [ ] MakerPilot 已启用，能在 Obsidian 里跟 Claude 对话

## 四、常见问题总表

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| `command not found: node` 或 `command not found: npm` | 没装 Node.js，或装完没重开终端 | 按第 6 项装，装完按 `Command + Q` 退出终端再打开 |
| `command not found: claude` | 装完没重开终端 | 退出终端重开；还不行就截图发群里 |
| 下载一直转圈，或报 `ETIMEDOUT`、`ECONNRESET`、`timed out` | 网络问题 | 回第 0.4 项和第 5 项检查网络；npm 相关的先确认换了国内镜像 |
| `EACCES` 或 `permission denied` | 没有管理员权限 | 截图发群里，我们一起处理 |
| 打开软件提示「无法验证开发者」 | Mac 的安全拦截 | 系统设置 → 隐私与安全性 → 点「仍要打开」 |
| `claude` 启动后让你选登录方式 | CC Switch 没启用，或终端是启用前打开的 | 回 CC Switch 点「启用」，关掉终端重开 |
| 报 `401` 或 `invalid api key` | Key 不全或带了空格 | 回 CC Switch 重新粘贴，或新建一个 Key |
| 共享屏幕对方只看到一个窗口 | 选了共享某个窗口 | 重新共享，选「整个屏幕」 |

记住一条：装软件的问题，九成不是网络就是权限。先从这两头查。
