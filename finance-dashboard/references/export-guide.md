# 账单导出指引

把下面对应平台的步骤直接发给用户。App 改版后入口名称可能略有变化，找不到时在账单页右上角的「···」或「常见问题」里找「下载账单」。

## 微信支付

1. 打开微信，点「我」→「服务」→「钱包」→「账单」
2. 点右上角「···」（部分版本在「常见问题」里），选「下载账单」
3. 用途选「用于个人对账」
4. 选时间范围。一次能选的跨度有上限，想看一整年就分几次导出
5. 填接收邮箱，完成身份验证
6. 几分钟后邮箱会收到一个压缩包，解压密码在「微信支付」公众号推送的消息里

解压后是 `微信支付账单流水文件(...)`，新版是 `.xlsx`，旧版是 `.csv`，两种都能直接用。

## 支付宝

1. 打开支付宝，点「我的」→「账单」
2. 点右上角「···」，选「开具交易流水证明」
3. 用途选「用于个人对账」
4. 选时间范围，填接收邮箱
5. 邮箱会收到一个压缩包，解压码在支付宝的消息通知里

解压后是 `支付宝交易明细(...).csv`，GBK 编码，用 Excel 打开可能乱码，不影响脚本读取。

## 给用户的话术

> 把微信和支付宝的账单导出来，解压后放进同一个文件夹，告诉我文件夹在哪就行。账单只在你电脑上处理，不会上传。时间范围建议选今年 1 月到现在，看得出变化。

## 常见问题

- **压缩包打不开**：密码区分大小写，复制的时候别带空格。
- **只有一个平台**：只用微信或只用支付宝也可以，仪表盘照常出，只是覆盖不全。
- **导了好几次，时间有重叠**：全放进同一个文件夹，脚本按交易单号去重。
- **想加上银行卡的流水**：脚本目前只认微信和支付宝的格式。银行卡里的大额收支（工资、房贷）用 `rules.local.json` 的 `manual` 手动补录。
