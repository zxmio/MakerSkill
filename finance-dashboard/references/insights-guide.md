# 洞察写作指南

洞察页回答三个问题：整体健不健康、钱主要去了哪、下个月可以调整什么。写之前把 `analysis.json` 通读一遍，需要更细的数字用 Python 读 `transactions.csv` 现算。

## insights.json 字段

```json
{
  "headline": "一句话结论，30 字以内为宜，说清最重要的一件事",
  "summary": "两三句话的整体判断：收入、支出、储蓄率，最大的两块支出，一个积极的变化",
  "indicators": [
    { "label": "储蓄率", "value": "29.3%", "level": "good", "note": "结余 ¥57,790，高于常说的 20% 线" }
  ],
  "findings": [
    { "title": "外卖是最大的习惯性支出", "metric": "¥15,718", "metric_label": "美团外卖 · 382 笔", "level": "warn", "body": "两三句话：事实、对比、原因" }
  ],
  "actions": [
    { "title": "晚饭外卖每周少点两次", "body": "具体怎么做，以及节省金额是怎么算的", "saving": "每月约省 ¥380" }
  ],
  "notes": ["口径说明，比如工资是手动补录的"]
}
```

- `headline`、`summary`、`findings`、`actions` 必填，`indicators`、`notes` 可选。
- `level` 取 `good`（健康）、`warn`（注意）、`bad`（偏高）、`info`（提示）。
- `indicators` 正好 4 个；`findings` 3 到 5 条；`actions` 3 到 4 条。
- `saving` 只在能算出节省金额时填，算不出来留空字符串。

## 四个指标怎么选

先从这几个里挑最能说明问题的 4 个：

| 指标 | 算法 | 参考线 |
|---|---|---|
| 储蓄率 | `totals.savings_rate` | 20% 以上 good，0–20% warn，负数 bad |
| 房租或房贷占收入 | 居住类月均 ÷ 月均收入 | 30% 以内 good，30–40% warn，以上 bad |
| 餐饮占支出 | 餐饮类 `share` | 只做提示，不评判 |
| 固定支出占支出 | `subscriptions` 月合计 ÷ 月均支出 | 越高越缺弹性 |
| 小额高频 | `habits.small_count`、`small_per_week` | 只做提示 |
| 深夜消费 | `habits.late_night_count` | 只做提示 |
| 未归类占比 | `uncategorized.share` | 超过 5% 就回去补规则，不要写进洞察 |

参考线是常见说法，不是标准答案。收入没补录全的情况下，不评价储蓄率。

## 发现从哪里找

按这个顺序扫一遍，挑最有信息量的 3 到 5 条：

1. **最大的一块**：支出构成第一名，它是硬成本（房租）还是习惯成本（外卖、网购）。
2. **变化**：哪个月明显高于月均，为什么（大额单笔、旅行、节日）；哪一类上下半年差别大。
3. **积少成多**：小额高频、某个商户笔数特别多（咖啡、便利店、打车）。
4. **固定支出**：每月自动扣的有哪些，有没有功能重复的会员、忘了取消的订阅。
5. **收入侧**：收入来源结构，副业或经营收款的趋势。
6. **时间习惯**：深夜消费、周末占比，跟用户的生活节奏对不对得上。

一条好的发现 = 一个数字 + 一个对比 + 一句解释。「外卖 382 笔」只是事实，「平均一天 1.3 单，下半年比上半年多 11%，和加班变多对得上」才是发现。

## 行动建议怎么写

- 从最容易做到的开始排，第一条最好是这周就能做的小动作。
- 每条都要具体到能执行：「晚饭外卖每周少点两次」，不写「减少外卖」。
- 节省金额要写清算法，比如「按晚饭平均每单 ¥44、每月 4.3 周算」，并用 Python 实际算一遍。
- 不是每条都要省钱。「副业收入单独记账」「年底出行提前留预算」这类帮用户看得更清楚的建议同样有价值。
- 不建议用户放弃明显让他生活变好的支出（健身、学习、陪家人），除非他自己说想控制。

## 语气

- 像一个帮你看账的朋友，平实、具体，不说教。
- 不贩卖焦虑，不用「月光」「败家」「剁手」这类带评判的词。
- 不用公文连接词（首先、其次、综上），段落短，口语连接词（所以、其实、但是）照用。
- 标题用名词短语或短句，不用感叹号，不用 emoji。
- 一次性的大额支出（旅行、换电脑）点明是一次性的，不要算成习惯。
